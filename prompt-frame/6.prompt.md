- 현재 섹션 구조
- 기존 레이아웃의 장점

을 유지하면서

기존 Placeholder 프로젝트를
실제 작업물 중심의 포트폴리오로 변경한다.

01

weAI를 활용하여

↓

02

VS Code에서

↓

03

필요한 부분을 수정하고 개선


↓

처럼 표현하지 마라.


AI 도구를 활용하여 초기 결과물을 만들고

VS Code 환경에서 결과물을 확인하고 수정하며

Claude를 코딩 보조 도구로 활용하여

웹사이트를 개선하고 완성한 프로젝트라는
실제 작업 과정을 정확하게 표현한다.

PROJECT 03 이미지 구성


대표 이미지

웹사이트의 완성된 화면을
가장 크게 보여준다.


상세 이미지

추가 웹사이트 화면을
보조적으로 배치한다.


브라우저 스크린샷을 사용할 경우

가능하면 불필요한

- 브라우저 주소창
- 탭
- 운영체제 UI

등이 과도하게 강조되지 않도록 한다.


단,

원본 이미지를 직접 수정하거나
원본 파일을 덮어쓰지 마라.


필요하다면

포트폴리오용 복사본을 생성하여 사용한다.


PROJECT 03에는

다른 프로젝트와 차별화되는

PROCESS 영역을 추가한다.


예시:


PROCESS


01

AI INITIAL CREATION

weAI를 활용하여
초기 웹사이트 구조 제작


02

PROJECT REVIEW

VS Code에서
프로젝트 구조와 코드 확인


03

EDIT & IMPROVEMENT

필요한 화면과 코드를
수정하고 개선


04

AI-ASSISTED CODING

Claude를 활용하여
코드 작업 보조


05

BUILD & TEST

브라우저에서 결과물을 확인하며
웹사이트 완성


위 문구는 참고용이다.

실제 포트폴리오 디자인에 어울리도록
간결하게 다듬어라.

"복사본"

만 포트폴리오용으로 사용한다.
