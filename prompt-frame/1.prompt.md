개인 이력서 및 포트폴리오 웹사이트를 제작하고 싶다.

이 프로젝트는 취업용 포트폴리오 사이트이며,
깔끔하고 전문적인 느낌을 주되 너무 딱딱하지 않은 디자인을 목표로 한다.

웹사이트는 PC와 모바일 환경 모두 지원하는 반응형 웹으로 제작한다.

기술 스택은 다음과 같다.

- React
- Vite
- CSS

필요한 경우 컴포넌트를 분리하여 관리하기 쉽게 작성한다.

웹사이트는 다음과 같은 섹션으로 구성한다.

1. Home
2. About Me
3. Skills
4. Projects
5. Portfolio
6. Contact

각 섹션은 하나의 긴 페이지에서 스크롤을 통해 이동할 수 있도록 제작한다.

상단에는 Navigation Bar를 배치하고,
각 메뉴를 클릭하면 해당 섹션으로 부드럽게 이동하도록 구현한다.

전체적인 디자인은 다음 방향을 따른다.

- 미니멀한 디자인
- 여백을 충분히 사용
- 가독성이 높은 타이포그래피
- 과도한 애니메이션은 사용하지 않음
- 프로젝트와 작업물을 강조하는 레이아웃
- 취업용 포트폴리오에 적합한 전문적인 분위기

먼저 전체 프로젝트 구조와 필요한 컴포넌트를 제안해라.

아직 코드를 작성하지 말고,
프로젝트 구조와 페이지 구성부터 설명해라.
