현재 포트폴리오 홈페이지의
실제 작업물 적용이 완료된 상태다.

이번 단계에서는

새로운 프로젝트를 추가하거나
홈페이지 구조를 크게 변경하지 않는다.

현재 결과물을 기반으로

"시각적 완성도와 포트폴리오 표현 방식"

을 개선한다.


==================================================
[이번 작업의 목표]
==================================================

현재 홈페이지의

- 다크 테마
- 보라색 포인트 컬러
- 미니멀한 분위기
- 섹션 구조
- 프로젝트 순서

는 유지한다.

새로운 디자인으로 다시 만들지 않는다.

이번 단계에서는

- 이미지 크기
- 이미지와 텍스트의 비율
- 프로젝트별 시각적 위계
- 여백
- 콘텐츠 밀도
- 프로젝트 간 리듬

을 개선한다.


==================================================
[가장 중요한 원칙]
==================================================

이 홈페이지는

개발자 포트폴리오가 아니라

콘텐츠 디자이너 및 그래픽 디자인 관련
직무 지원을 위한 포트폴리오다.

따라서

텍스트보다 실제 작업물이
더 중요한 시각적 요소가 되어야 한다.

사용자가 페이지를 스크롤할 때

먼저 작업물을 보고

그 다음 프로젝트 내용을 읽는

흐름이 자연스럽도록 개선한다.


==================================================
[전체적인 디자인 개선]
==================================================

현재 페이지가
텍스트와 프로젝트 정보의 비중에 비해

일부 실제 작업물 이미지가
상대적으로 작게 느껴질 수 있다.

전체 프로젝트를 확인하고

다음 요소를 조정해라.


- 대표 이미지 크기
- 이미지 Grid 크기
- 이미지 사이의 간격
- 프로젝트 설명 길이
- 프로젝트 정보 밀도
- 프로젝트 사이의 여백


단,

이미지를 무조건 크게 만들지 마라.

프로젝트의 성격에 따라

대표 이미지

와

보조 이미지

사이에 명확한 시각적 위계를 만든다.


==================================================
[텍스트 밀도 조정]
==================================================

현재 프로젝트 설명과
제작 목적 등의 텍스트를 확인한다.

불필요하게 긴 문장이 있다면

의미를 유지하면서
더 간결하게 정리한다.


프로젝트의 설명은

한눈에 읽을 수 있는 정도로 유지한다.


다음과 같은 정보는

필요한 경우 짧게 정리한다.


- 프로젝트 소개
- 제작 목적
- 역할
- 사용 도구


모든 프로젝트에
동일한 양의 텍스트가 반드시 필요하지 않다.

프로젝트의 성격에 따라
정보의 양을 조절한다.


==================================================
[PROJECT 01 — CHAMTOON]
==================================================

CHAMTOON은

콘텐츠 디자인 포트폴리오에서
가장 중요한 대표 프로젝트 중 하나다.


대표 이미지의 존재감을 유지한다.

하지만

세부 콘텐츠 이미지가
너무 작거나 단순한 보조 요소처럼
보이지 않도록 확인한다.


대표 이미지

↓

프로젝트 정보

↓

주요 콘텐츠 이미지

의 흐름이 자연스러운지 확인한다.


세부 이미지의

- 크기
- 간격
- Grid 비율

을 조정하여

정보성 콘텐츠 시리즈라는 점이
잘 보이도록 개선한다.


==================================================
[PROJECT 02 — 썸앤데코]
==================================================

이 프로젝트는

다양한 목적의
브랜드 SNS 콘텐츠를 제작한 작업이다.


현재 이미지 배열을 확인하고

모든 이미지가
동일한 중요도로 보이지 않도록 한다.


가장 완성도가 높고

프로젝트의 성격을 잘 보여주는
대표 콘텐츠는 조금 더 강조한다.


나머지 콘텐츠는

Grid 또는 자연스러운 배열을 통해

다양한 콘텐츠 포맷을
보여주는 역할을 한다.


프로젝트 소개 문구에서도

"다양한 목적의 SNS 콘텐츠"

라는 프로젝트의 성격이
명확하게 드러나는지 확인한다.


==================================================
[PROJECT 03 — 춘천마임축제]
==================================================

이 프로젝트는

다른 프로젝트와 차별화되는
웹 기반 작업이다.


현재 프로젝트의

- 대표 웹사이트 이미지
- 프로젝트 설명
- 제작 과정
- 상세 이미지

사이의 시각적 위계를 확인한다.


특히

대표 웹사이트 결과물이
충분히 눈에 띄는지 확인한다.


웹사이트 이미지는

다른 프로젝트의 이미지보다
작거나 약하게 보이지 않도록 한다.


PROJECT 03의 PROCESS 영역은 유지한다.


하지만

과도하게 기술적인
개발 문서처럼 보이지 않도록 한다.


PROCESS는

AI 기술을 자랑하는 영역이 아니라

실제 제작 워크플로우를
간결하게 보여주는 역할을 한다.


실제 사용한 도구만 유지한다.


- weAI
- VS Code
- Claude


Figma를 추가하지 마라.


==================================================
[PROJECT 04 — 명란젓 연대기]
==================================================

이 프로젝트는

썸네일 시리즈의
시각적인 다양성이 장점이다.


현재 9개의 썸네일 Grid를 확인한다.


대표 썸네일과

나머지 썸네일 사이의
시각적 차이가 충분한지 확인한다.


필요하다면

대표 썸네일의 크기를
조금 더 강조할 수 있다.


나머지 썸네일은

통일된 Grid를 유지한다.


썸네일 이미지가
너무 작아서 내용을 확인하기 어렵지 않은지
확인한다.


데스크톱과 모바일 모두에서

썸네일이 충분히 보이는 크기를 유지한다.

[Hero Section]
==================================================

현재 Hero Section의

작업물 이미지 영역을 확인한다.


현재의 기본 구조는 유지한다.


다만

이미지가 지나치게 작거나
단순한 장식처럼 보이는 경우

대표 작업물과 보조 작업물 사이의

현재 사용 중인 이미지를 기반으로

더 의도적인 포트폴리오 콜라주처럼
보이도록

- 이미지 크기
- 위치
- 겹침 정도
- 간격

만 조정할 수 있다.
