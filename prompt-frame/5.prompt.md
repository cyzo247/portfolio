PROJECT 03

2026 춘천마임축제 웹사이트

카테고리:
WEB DESIGN / AI-ASSISTED WEB DEVELOPMENT

이 프로젝트의 실제 제작 과정을 정확하게 반영해야 한다.

이 프로젝트는 다음과 같은 과정으로 제작했다.

1. weAI를 활용하여 웹사이트의 초기 결과물과 기본 구조를 제작했다.

2. 생성된 결과물을 그대로 사용하지 않았다.

3. VS Code 환경에서 프로젝트를 직접 확인하고 수정했다.

4. Claude를 활용하여 코드 작성과 수정 작업을 보조받았다.

5. VS Code에서 실제 코드를 수정하고 확인하면서
   웹사이트를 구축하고 완성했다.

따라서 이 프로젝트를 단순히

"AI가 웹사이트를 만들어준 프로젝트"

처럼 표현해서는 안 된다.

반대로

"모든 코드를 처음부터 직접 작성한 순수 개발 프로젝트"

처럼 표현해서도 안 된다.


이 프로젝트의 핵심은

AI 기반 제작 도구를 활용하여 초기 결과물을 만들고,

그 결과물을 이해하고 검토하면서

VS Code 환경에서 직접 수정하고,

Claude를 코딩 보조 도구로 활용하여

웹사이트를 개선하고 구축한 경험이다.


포트폴리오에서는 다음과 같은 역량을 보여주는 방향으로 구성한다.

- AI 기반 제작 도구 활용 능력
- 웹사이트 구조 이해
- 기존 코드 수정 및 개선
- VS Code를 활용한 개발 환경 사용
- Claude를 활용한 AI 기반 코딩 작업
- 웹사이트의 디자인 및 화면 구성
- 생성형 AI를 활용한 제작 워크플로우 경험


중요한 것은

"AI가 대신 만들어줬다"

라는 느낌이 아니라,

"AI 도구를 활용하면서 결과물을 검토하고
직접 수정 및 개선하여 완성했다"

라는 제작 과정이 드러나는 것이다.


이 프로젝트는 개발 기술 자체를 과도하게 강조하지 않는다.

디자인 포트폴리오이므로

"어떤 기술을 사용했는가"

보다

"AI 기반 제작 도구와 코딩 환경을 활용하여
웹사이트를 어떻게 구축하고 개선했는가"

를 보여주는 방향으로 구성한다.

↓

05

웹사이트 구축 및 확인

실제 브라우저 환경에서
결과물을 확인하고 수정하며 완성

선택 이미지

- 세부 작업 과정
- 추가 콘텐츠
