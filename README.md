# 이지안 — Portfolio

콘텐츠 디자인을 중심으로 다양한 시각 콘텐츠를 제작해 온 포트폴리오 웹사이트입니다.

SNS 콘텐츠, 정보성 콘텐츠, 브랜드 콘텐츠, 웹사이트, 썸네일 등
다양한 형태의 디자인 작업을 소개합니다.
